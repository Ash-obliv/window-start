亦安快速启动 — 详细使用说明
====================================

一、软件定位
------------
亦安快速启动是一款面向 Windows 的轻量启动器，用于集中管理常用程序、文件夹、各类文档与网页链接。
它支持拖放添加、分组管理、搜索筛选、右键快捷操作、托盘常驻与快捷键唤起，适合日常高频启动场景。


二、主要功能
------------
1) 项目添加
- 支持将以下内容直接拖入窗口添加到当前分组：
- 可执行程序（.exe）
- 快捷方式（.lnk / .url）
- 文件夹
- 常见文档、图片等文件
- 拖拽文本中含有 http(s) 的链接（可从记事本、浏览器地址栏或书签等拖入）
- 如果拖入的文本是网页链接，程序会自动按网页方式保存，并尝试获取站点图标。

2) 项目启动
- 左键单击图标即可启动对应项目。
- 右键单击图标可选择管理员方式启动程序。
- 支持记录使用频率，常用项目会优先排序显示。

3) 搜索与筛选
- 顶部搜索框可按关键字筛选当前分组项目。
- 匹配范围：名称、路径、关键词、网页地址。
- 搜索结果支持高亮显示。
- 点击结果区域空白可快速退出搜索，恢复当前分组完整列表。

4) 图标与显示
- 图标为无边框纯图标风格，标题在不同主题下保持可读。
- 标题最多显示12个字，超出自动省略。
- 支持悬停/按下动效，提升操作反馈。

5) 分组管理
左侧分组支持：
- 一键启动分组下所有程序（包括可执行程序、网页、文件夹等）
- 单击切换分组
- 双击重命名，重命名后按回车键保存
- 上下拖拽分组调整顺序
- 分组上右键菜单：新增分组、重命名、删除分组
- 删除分组时会同步删除该分组内所有项目。
- 当删除到最后一个分组时，程序会自动创建一个默认空分组，保证可继续使用。

6) 项目右键菜单
在项目图标上右键可执行：
- 置顶到最前 / 取消置顶
- 以管理员身份运行
- 打开所在位置
- 查看属性
- 编辑项目信息（名称、路径、参数、分组、排序）
- 删除项目

7) 拖拽交互
- 将项目拖到左侧分组标签上：将项目快速移动到该分组。
- 将项目拖出窗口到外部：可在资源管理器中释放生成快捷方式（便于桌面导出）。
- 将快捷方式拖入程序窗口可自动解析快捷方式指向的主程序位置

8) 托盘与窗口行为
- 关闭主窗口后默认隐藏到托盘，不退出程序。
- 托盘右键菜单支持：显示/隐藏主窗口、打开设置、查看说明、退出程序。
- 双击托盘图标可快速显示/隐藏主窗口。
- 单击托盘图标激活主程序窗口

9) 设置功能
设置窗口支持：
- 保持窗口最前
- 开机自启
- 启动后最小化
- 窗口贴边自动隐藏
- 单击运行隐藏窗口
- 绝对路径 / 相对路径转换
- 快捷键预设（键盘单独按键、组合按键，鼠标的中键、侧键）
- 更换背景图（可自定义图片）
- 自定义设置图标大小
- 窗口透明度
- 主题皮肤切换
- 使用说明 / 关于 / 退出

三、排序与置顶规则
------------------
- 置顶项目始终排在分组最前。
- 多个置顶项目按“置顶操作时间”先后排列。
- 非置顶项目按使用频率、排序权重等规则综合排序。


四、性能与内存优化细节（当前版本）
--------------------------------

1) 搜索性能优化
- 建立运行时搜索索引，减少重复字符串转换。
- 搜索结束后及时释放索引缓存，避免长期占用内存。

2) 图标加载与缓存优化
- 图标缓存采用LRU策略，限制缓存上限，避免程序使用时持续增长内存。
- 图标写入缓存前会做统一尺寸归一化，减少单图内存占用。
- 图标缓存支持按场景主动瘦身（如窗口隐藏到托盘后）。

3) 列表刷新优化
- 刷新时仅构建当前可见列表模型，减少不必要的全量数据驻留。
- 过滤与匹配流程减少中间结构分配，降低 CPU 和内存抖动。

4) 托盘常驻内存回收
- 程序支持周期性内存回收。
- 窗口隐藏/最小化时会执行更积极的缓存回收与工作集整理，降低内存占用。

五、常见问题
------------
1) 为什么关闭窗口程序还在？
- 这是托盘常驻设计。请在托盘右键菜单中选择“退出程序”以完全退出。

2) 为什么有些图标和源文件不完全一致？
- 为降低内存占用，程序会对图标进行统一尺寸处理；这不影响功能。

3) 删除分组后还能继续用吗？
- 可以。删除最后一个分组时会自动补一个默认空分组。

4) 为什么杀毒软件会提示报毒？
- 本程序为个人开发，并未提交给任何机构检测和备案，也未进行数字签名，所以会被一些审核规则严格的杀软误报。加上本程序有自启动功能属于敏感操作指令（恶意程序通常会进行自启动设定来维持权限），有联网操作（通过访问拖入的网址获取网站默认图标），有窗口隐藏功能（最小化必须用到隐藏没有办法）。为防止有人恶意二次开发、转售，同时也方便大家及时获取更新提示，所以我增加了联网的更新验证，这种行为也会导致杀软误报。当然这种更新验证会默认在没有网络的时候不进行验证，且只会在运行时验证一次，大家不必担心无法联网时影响使用的问题。后期我会将程序上传沙箱及世界多家知名杀软的查杀平台导出程序报毒和行为报告，用于打消大家的使用顾虑，同时也欢迎各位逆向分析的高手对本程序进行安全性检测和提出提升建议，程序没有进行加壳和代码混淆，也没有任何的暗桩和恶意反击代码所以请放心食用。因为一旦加密就会直接影响到程序的运行效率，并且会成倍增加进程的内存占用，这违背了我做这款程序的初衷，所以决定本程序不进行任何形式的代码保护。至于开源方面目前没有打算，毕竟写这么一个程序还是挺辛苦的也构思了很久，不希望开源后有人一扭头拿到闲鱼1毛钱一份给卖掉，等我哪一天不准备继续更新本层序的时候会考虑进行开源，供有能力的人继续开发完善各种功能。
